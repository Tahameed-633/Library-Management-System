# 📚 Library Management System (C++)

A simple console-based **Library Management System** developed in **C++** using file handling. This project allows a librarian to manage books by adding, searching, borrowing, returning, and updating book information. All data is stored permanently in a text file.



## ✨ Features

- 🔐 Password Protected Login
- ➕ Add New Book
- 🔍 Search Book by ID
- 📖 Borrow Book
- ↩️ Return Book
- ✏️ Update Book Information
- 💾 File Handling (Data stored in `library.txt`)
- 🖥️ Console-based User Interface



## 🛠️ Technologies Used

- **Language:** C++
- **IDE:** Code::Blocks 20.03
- **Concepts Used:**
  - Structures (`struct`)
  - Functions
  - Arrays
  - File Handling (`ifstream`, `ofstream`)
  - String Handling
  - Menu Driven Programming
